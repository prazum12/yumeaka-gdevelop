第2章

ナイフを自動で投げよう

📅 第2回の講習で使います（日付が決まったらここに記載）
💻 使っているPC:

🎯 この章でできるようになること

  • シーン変数を作って、数や「真・偽」を覚えておける
  • シーンタイマーで、決まった間隔ごとにアクションを動かせる
  • 「Repeat」（くり返し）のイベントで、同じアクションを何回もくり返せる
  • 騎士が向いている方向へ、ナイフを自動で飛ばせる

このゲームでは、プレイヤーはナイフをねらって投げません。
決まった間隔で、騎士が向いている方向へナイフが自動で飛んでいきます。
プレイヤーは動いて、敵をよけることに集中できます。

2-1. この章で作るしくみ

この章で作るルール（まとめ）
条件騎士が動いている
アクション動いている向きを FaceAngle に覚えておく
条件シーンが始まった
アクションナイフ用のタイマーをスタート
条件タイマーが KnifeCooldown 秒をこえた
アクションタイマーをリセット、音を鳴らす
（本数 × 方向の数）回くり返して、ナイフを作って飛ばす
条件ナイフが騎士から遠くなった
アクションナイフを消す

2-2. ナイフと変数を用意しよう

1ナイフを追加する

「Objects」の「＋」から Dungeon のパックを開き、「Weapon」の中の「Knife」を選んでプロジェクトに追加します。
ナイフはイベントで作り出すので、シーンに置かなくてOK。
もし置いてしまったら、シーンのナイフをクリックして Delete キーで消しておこう。

2シーン変数を作る

「Game Scene」のタブで、ステージの外の何もないところをクリックします。
左の「Scene Variables」の右の、四角から矢印が出たマークを押すと、「Game Scene variables」の画面が開きます。
「Add variable」で次の7つを作り、「Apply」を押します。

名前型値意味
FaceAngleNumber0騎士が向いている方向（角度）
KnifeCooldownNumber1何秒ごとにナイフを投げるか
KnifeCountNumber11回に投げる本数
KnifeDirsNumber1投げる方向の数
KnifeIndexNumber0今、何本目を投げているか
ShotAngleNumber0今投げるナイフの角度
LevelingUpBooleanFalseレベルアップ中かどうか（第4章で使う。
今は False のまま）
シーン変数 … シーンに1つだけある「数や文字を入れておく箱」。
型が「Number」なら数を、「Boolean」（真偽値）なら「True」（真＝はい）か「False」（偽＝いいえ）のどちらかを覚えます。
ナイフの本数や間隔を変数にしておくと、第4章のレベルアップで数を変えるだけで強くできます。
3騎士の向きを覚えておく

「Game Scene (Events)」を開き、Player グループのいちばん下に新しいイベントを作ります。
条件は「Is moving」で Player。
アクションは change variable value で検索 →「Change variable value」、Variable は FaceAngle、Modification's sign は「= (set to)」、Value は下の式。

Value
Player.TopDownMovement::Angle()
FaceAngle のわけ … Player.TopDownMovement::Angle() は、騎士が今歩いている方向を角度で教えてくれる式です。
右が 0、下が 90、左が 180、上が 270（−90）です。
でも、止まっているときは歩いていないので、方向がわかりません。
そこで「動いているときだけ」FaceAngle に覚えておけば、止まったあとも最後に向いていた方向へナイフを投げられます。

2-3. タイマーでナイフを投げよう

4シーンが始まったらタイマーをスタート

右下の「+ Add...」→「Event group」で、新しいグループ Start を作ります。
その中に、条件 beginning of the scene →「At the beginning of the scene」のイベントを作ります。
アクションは start (or reset) a scene timer で検索 →「Start (or reset) a scene timer」、Timer's name は "KnifeTimer"（ダブルクォーテーションごと入れる）。
これがないとタイマーが動かず、ナイフが1本も飛びません。

5KnifeCooldown 秒ごとに動くイベントを作る

もう1つ新しいグループ Knife を作り、その中にイベントを作ります。
条件は2つです。

  • variable value で検索 →「Variable value」、Variable は LevelingUp、「False」
  • scene timer で検索 →「Value of a scene timer」、Timer's name は "KnifeTimer"、Sign of the test は「≥ (greater or equal to)」、Time in seconds は KnifeCooldown

アクションは3つです。

  • 「Start (or reset) a scene timer」で "KnifeTimer"（0にもどして、また数えはじめる）
  • 「Change variable value」で KnifeIndex を「= (set to)」0
  • 投げる音（下の説明）

音は play a sound で検索 →「Play a sound」を選びます。
「Choose the audio file to use」の欄をクリックして、「Choose from asset store」を押そう。

検索欄に throw と入力すると、「sfx_throw.ogg」（作者: Kenney、CC0）が出てきます。
左の ▷ を押すと、音をためしに聞けます。
選んで「Add to project」を押します。
もとの画面にもどったら、Volume（音の大きさ）に 30 と入れて「Ok」。
音がなくてもナイフは飛ぶので、うまくいかないときはあとまわしでも大丈夫です。

シーンタイマー … シーンの中で時間を数えるストップウォッチ。
名前をつけて、いくつでも使えます。
「KnifeCooldown 秒たったら → リセットして投げる」をくり返すので、1秒ごとにナイフが飛びます。
LevelingUp の条件は、第4章でレベルアップの画面を出しているあいだ、ナイフを止めるためのものです。

2-4. くり返しでナイフを作ろう

6「Repeat」（くり返し）を入れる

今作ったイベントを右クリックして、「Add」→「Repeat」を選びます（「Sub Event」ではありません）。
繰り返す回数には下の式を入れます。

繰り返す回数
KnifeDirs * KnifeCount

写真のように、繰り返しのイベントがタイマーのイベントの中（一段右にずれた場所）に入っているか確かめよう。
ずれていないときは、ドラッグしてタイマーのイベントの中に入れます。
イベントシートには「Repeat KnifeDirs * KnifeCount times:」と表示されます。

本数 × 方向の数 … KnifeCount（本数）が 2、KnifeDirs（方向の数）が 2 なら、2 × 2 ＝ 4本投げます。
今はどちらも 1 なので、1回だけくり返して、1本だけ投げます。
第4章のレベルアップで、この数がふえていきます。
7繰り返しの中のアクションを入れる

繰り返しのイベントに、アクションを6つ入れます。
上から順番に入れよう。

  1. create an object で検索 →「Create an object」、Knife を X Player.CenterX()、Y Player.CenterY() に作る
  2. 「Change variable value」で ShotAngle を「= (set to)」、Value は下の式
  3. angle で検索 →「Angle」、Knife を「= (set to)」ShotAngle + 90
  4. 左の一覧で Knife を選び、「Add a force (angle)」、Angle ShotAngle、Speed (in pixels per second) 650、下は「Permanent」
  5. scale で検索 →「Scale」、Knife を「= (set to)」3（3倍の大きさ）
  6. 「Change variable value」で KnifeIndex を「+ (add)」1
ShotAngle の値（おまじない）
FaceAngle + floor(KnifeIndex / KnifeCount) * 360 / KnifeDirs + (mod(KnifeIndex, KnifeCount) - (KnifeCount - 1) / 2) * 12
ShotAngle の式（おまじない） … むずかしい式なので、コピーしてそのまま使えばOK。
でも、中身はこんなことをしています。
  • FaceAngle … 騎士が向いている方向が、スタートの角度
  • floor(KnifeIndex / KnifeCount) * 360 / KnifeDirs … 何番目の方向かを決めて、360度を方向の数で分けた分だけ回す（方向が2つなら前と後ろ、4つなら十字）
  • (mod(KnifeIndex, KnifeCount) - (KnifeCount - 1) / 2) * 12 … 同じ方向に何本も投げるとき、12度ずつ扇のように広げる
今は KnifeDirs も KnifeCount も 1 なので、うしろの2つは 0 になります。
つまり今は、ShotAngle は FaceAngle と同じ角度です。
+ 90 のわけ … Knife の画像は、もともと上を向いています。
そのままだと横向きに飛んでしまうので、90度足して、刃先が飛ぶ方向を向くようにしています。
Permanent … 一度つけたら、ずっと同じ方向に押しつづけるフォース（力）。
「Instant」にすると、一瞬だけ押されてすぐ止まってしまいます。
イベントシートには「Add to Knife a permanent force, angle: ShotAngle degrees and length: 650 pixels」と表示されます。
8遠くへ行ったナイフを消す

Knife グループに新しいイベントを作ります（繰り返しの中ではなく、タイマーのイベントの下）。
条件は、左の一覧で Knife を選び、「Distance between two objects」、Object 2 は Player、Distance は 700。
「Invert condition」をONにして「700 より遠い」にします。
アクションは「Delete the object」で Knife。

イベントシートには「Knife distance to Player is below 700 pixels」と出て、反転のしるしがつきます。
遠くへ行ったナイフを消さないと、見えないナイフがどんどんたまって、ゲームが重くなってしまいます。

9保存して Preview

保存してから Preview します。
止まっていても動いていても、1秒ごとに、騎士が向いている方向へナイフが飛んでいきます。
右へ歩けば右へ、上へ歩けば上へ飛びます。
音を入れた人は、投げるたびに「シュッ」と鳴れば成功！

💪 やってみよう

シーン変数の KnifeCount を 3 にして Preview してみよう。
次に KnifeDirs を 4 にしてみよう。
ナイフの飛び方がどう変わるか、たしかめたら 1 にもどしておこう。

ヒント

KnifeCount を 3 にすると、同じ方向に3本が扇のように広がって飛びます。
KnifeDirs を 4 にすると、前・うしろ・左右の4方向に飛びます。
これが第4章のレベルアップで手に入る強化です。

2-5. 🚨 つまずきポイント集

ナイフが1本も飛ばない

原因1: 「At the beginning of the scene」でタイマーをスタートしていない、またはタイマーの名前がちがう。
→ 2か所とも "KnifeTimer" になっているか、大文字・小文字まで確かめよう。

原因2: LevelingUp の値が「True」になっている。
→ シーン変数の画面で、LevelingUp が「False」になっているか確かめよう。

ナイフが出るけど動かない

原因: フォースが「Instant」になっている。

直し方: 「Add a force (angle)」を開いて、「Permanent」を選びなおそう。

ナイフが横向きのまま飛ぶ

原因: Angle の式に「+ 90」がない。

直し方: Knife の Angle が ShotAngle + 90 になっているか確かめよう。

ナイフがものすごくたくさん出る

原因: 「Start (or reset) a scene timer」を入れ忘れた、または繰り返しの中に入れてしまった。

直し方: タイマーのリセットは、繰り返しの外（タイマーのイベントのアクション）に入れよう。

いつも右にしか飛ばない

原因: FaceAngle を覚えるイベントがない、または ShotAngle の式に FaceAngle が入っていない。

直し方: Player グループに「Is moving → FaceAngle ＝ Player.TopDownMovement::Angle()」があるか確かめよう。
