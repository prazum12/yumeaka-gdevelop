第5章

ゾンビをたおそう

📅 第5回の講習で使います（日付が決まったらここに記載）
💻 使っているPC:

🎯 この章でできるようになること

  • オブジェクト変数で、ゾンビ1体ずつに体力を持たせられる
  • 3Dの当たり判定（Collision in 3D）を使える
  • タイマーで、何秒かごとにゾンビをわかせられる
  • HP が 0 になったら、ゲームをやり直しにできる
  • 式を使って、たおすほどゾンビが早くわいてくるようにできる
  • 目標の数だけたおすと、ボスが出てくるしくみを作れる

5-1. この章で作るしくみ

ゾンビは弾を3発当てるとたおれます。
トラックでひいても、たおせます。
たおした数を「Kills」として画面に出し、3秒ごとに新しいゾンビがわいてくるようにします。
そのあと、たおすほどわいてくる間かくが短くなるようにします。
最後に、ゾンビを20体たおすと大きなボスが出てきて、ボスをたおすとクリアの画面に進むようにします。

5-2. 変数と文字を用意しよう

1ゾンビに体力（オブジェクト変数）を持たせる

シーンエディターで、一覧の Zombie をクリックします。
左の「Object Variables」の右の、四角から矢印が出たマークを押します。
「Add variable」を押して、名前を Health、型は「Number」のまま、値を 3 にして「Apply」。

オブジェクト変数 … オブジェクト1つ1つが、べつべつに持っている変数。
第4章の PlayerHealth は「シーン変数」で、ゲーム全体に1つだけです。
Health はゾンビ1体ずつが持っているので、1体目は残り1、2体目は残り3、のように別々に数えられます。
2シーン変数を2つふやす

シーンの何もないところをクリックして、「Scene Variables」の編集画面を開きます（第4章と同じ）。
「Add variable」で次の2つを作ります。
どちらも型は Number、値は 0 のままでOK。

  • Kills … たおしたゾンビの数
  • SpawnAngle … 新しいゾンビをわかせる向き
3Kills の文字を作る

一覧の HealthText の「⋮」から「Duplicate」（コピーを作る）を選びます。
「HealthText2」ができて名前を入力できる状態になるので、KillText と入力して Enter。
左の「Text」の欄を Kills: 0 に書きかえます。

次に、Layers パネルで UI の「○」を●にしてから、KillText の「⋮」→「Add instance to the scene」でシーンに置きます。
置いた文字をクリックして、X を 20、Y を 160 にします（HP の下）。
最後に、●を Base layer にもどしておこう。

ドラッグしても置けないとき

一覧からシーンへのドラッグがうまくいかないことがあります。
そのときは「⋮」→「Add instance to the scene」を使うと、画面のまん中に置かれます。

5-3. 弾でたおそう

イベントシートで、新しいグループ Battle（たたかい）を作り、Shift + D で中にイベントを作ります。

4弾が当たったら体力をへらす

条件は collision で検索して「Collision in 3D」（3Dでぶつかった）を選びます。
Object は Bullet、Other object は Zombie。
「3D capability」の欄は自動で「Object3D」になるので、さわらなくてOK。

アクションは2つ。

  • 「Delete the object」で Bullet
  • change object variable value で検索 →「Change object variable value」、Object は Zombie、Variable は Health、Modification's sign は「- (subtract)」、Value は 1
Collision in 3D … スターターに最初から入っている「3D collision」の拡張機能（あとから足せる追加の機能）で使える条件。
高さ（Z）もふくめて、本当にぶつかっているかを調べてくれます。
ふつうの「Collision」は上から見た形だけで調べるので、3Dのゲームではこちらを使います。
5体力が 0 になったらたおす

Shift + A で新しいイベントを作ります。
条件は object variable value で検索 →「Object variable value」。
Object は Zombie、Variable は Health、Sign of the test は「≤ (less or equal to)」（〜以下）、値は 0。

アクションは2つ。

  • 「Delete the object」で Zombie
  • 「Change variable value」で Kills を「+ (add)」（足す）で 1

5-4. トラックでたおそう

6トラックに近づいたゾンビを消す

Shift + A で新しいイベントを作ります。
条件は2つ。

  • 「Variable value」で InCar が True（乗っている）
  • 「Distance between two objects」で Zombie と Truck、距離 80

アクションは、ステップ5と同じ2つ（Zombie を消す、Kills に1を足す）です。

同じアクションを何回も作るのがめんどう

ステップ5のアクション2つを、Shift を押しながらクリックして両方選び、Ctrl + C（Mac は ⌘ + C）でコピーできます。
ステップ6のイベントのアクション側をクリックして Ctrl + V（Mac は ⌘ + V）で貼りつけよう。

5-5. ゾンビをわかせよう

73秒ごとに動くイベントを作る

Shift + A で新しいイベントを作ります。
条件は value of a scene timer で検索 →「Value of a scene timer」（シーンのタイマーの値）。
Timer's name は "SpawnTimer"（ダブルクォーテーションもつける）、Sign of the test は「≥ (greater or equal to)」（〜以上）、Time in seconds は 3。
この 3 は、あとの 5-8 で式に変えます。
まずは 3 秒のまま作って、動くことを確かめよう。

8ランダムな場所にゾンビを作る

アクションは3つです。

  • start (or reset) a scene timer で検索 →「Start (or reset) a scene timer」、名前は "SpawnTimer"（0にもどして、また数えはじめる）
  • 「Change variable value」で SpawnAngle を「= (set to)」で下の式
  • 「Create an object」で Zombie、X と Y は下の式
SpawnAngle（ランダムな向き）
RandomInRange(0, 359)
X position
Player.X() + XFromAngleAndDistance(SpawnAngle, 700)
Y position
Player.Y() + YFromAngleAndDistance(SpawnAngle, 700)
RandomInRange(0, 359) … 0 から 359 までの数を、ランダム（でたらめ）に1つ選ぶ式。
第3章で使った XFromAngleAndDistance と組み合わせると、「主人公を中心にした円の上の、どこか1か所」になります。
だから、ゾンビはいつも主人公から同じくらいはなれた、いろいろな方向からやってきます。
9ゲームの最初にタイマーをスタートする

タイマーは、スタートさせないと数えはじめません。
Shift + A で新しいイベントを作り、条件は at the beginning で検索 →「At the beginning of the scene」。
アクションは「Start (or reset) a scene timer」で "SpawnTimer"。

5-6. Kills と、やられたときのしくみ

10Kills を画面に出す

Shift + A で新しいイベントを作ります。
条件はなし。
アクションの画面で、左の一覧から KillText を選び、「Text」を選びます。
Text の欄に次の式を入れます（第4章の HP と同じやり方）。

KillText に入れる式
"Kills: " + ToString(Kills)
11HP が 0 になったら最初から

Shift + A で新しいイベントを作ります。
条件は「Variable value」で PlayerHealth、Sign of the test は「≤ (less or equal to)」、値は 0。
アクションは change the scene で検索 →「Change the scene」、Name of the new scene は一覧から「Game Scene」。
今のシーンをもう一度始めるので、最初からやり直しになります。
第6章で「GAME OVER」の画面を作ったら、ここをその画面に進むように変えます。

5-7. たたかってみよう

12保存して Preview

保存してから Preview します。
ゾンビに弾を3発当てるとたおれて、左上の Kills がふえます。
トラックに乗って、ゾンビをひいてみよう。
3秒ごとにゾンビがふえていくので、どこまでたおせるかチャレンジ！

5-8. だんだんむずかしくしよう

ずっと3秒ごとだと、なれてくると少しかんたんです。
たおせばたおすほど、ゾンビがわいてくる間かくが短くなるようにします。

13わく間かくを式にする

Battle グループの「The timer "SpawnTimer" ≥ 3 seconds」の条件をダブルクリックして開きます。
「Time in seconds」の 3 を消して、下の式を入れて「Ok」。

Time in seconds
max(1, 3 - Kills * 0.08)
max(1, 3 - Kills * 0.08) … 3 - Kills * 0.08 は、たおすたびに 0.08 秒ずつ短くなる時間。
0体なら3秒、10体なら2.2秒、20体なら1.4秒です。
ただ、このままだと25体をこえると1秒より短くなり、もっとたおすと0秒やマイナスになって、ゾンビがわきすぎてしまいます。
max(1, …) は「2つのうち大きいほう」を選ぶ式なので、いちばん短くても1秒で止まります。
14できあがったイベントを確かめる

Battle グループの中が、下の写真と同じ7つのイベントになっていればOK。

5-9. ボスの準備をしよう

ゾンビを20体たおすと、大きなボスが出てくるようにします。
まずは、目標の数を入れる変数、画面の文字、ボスのオブジェクトを用意します。

15シーン変数 Goal と BossSpawned を作る

シーンの何もないところをクリックして、「Scene Variables」の編集画面（「Game Scene variables」）を開きます。
「Add variable」で次の2つを作って、「Apply」を押します。

  • Goal … 型は「Number」、値は 20（ボスが出るまでにたおす数）
  • BossSpawned … 型は「Boolean」、値は「False」のまま（ボスをもう出したか）
16GoalText と BossHPText を作って置く

一覧の HealthText の「⋮」→「Duplicate」で文字のオブジェクトを作り、名前を GoalText にします（ステップ3の KillText と同じやり方）。
左の Properties で、次のようにします。

  • Text: ゾンビを20体たおすと、ボスが出てくる！
  • Font size: 30
  • Color: 255;235;80（黄色）

同じように HealthText を Duplicate して BossHPText を作ります。

  • Text: BOSS HP: 40
  • Font size: 36
  • Color: 255;80;80（赤）

Layers パネルで UI に●をつけてから、2つともシーンに置きます。
GoalText は X 220・Y 22（画面の上）、BossHPText は X 990・Y 20（右上）にします。
最後に、●を Base layer にもどしておこう。

17ボスのオブジェクトを作る

一覧の Zombie の「⋮」→「Duplicate」を選びます（第1章の「Swap assets」と同じメニューの中にあります）。
「Zombie2」ができて名前を入力できる状態になるので、Boss と入力して Enter。
Boss をクリックして、左の「Default size」の Width・Height・Depth を全部 210 にします（ゾンビの3倍）。
左の「Object Variables」には、Duplicate でコピーされた Health（3）があるので、値を 40 にします。
ボスはイベントで作り出すので、シーンには置かなくてOK。

18Clear のシーンを先に作っておく

ボスをたおしたら「Clear」というシーンに進むようにします。
Clear の中身（クリアの画面）は第6章で作りますが、イベントで選べるように、先にシーンだけ作っておきます。
左上の「≡」（メニュー）を押して、プロジェクトマネージャーを開きます。
「Scenes」の右の「＋」を押すと、新しいシーンができます。
できたシーンの「⋮」→「Rename」で、名前を Clear にします。
終わったら、上のタブで「Game Scene (Events)」にもどります。

くわしいやり方は、第6章の 6-2 にも写真つきでのっています。
先に第6章の 6-2 の手順1をやっておいてもOK。

5-10. ボスのイベントを作ろう

イベントシートで、新しいグループ Boss を作り（「+ Add...」→「Event group」）、Shift + D で中にイベントを作ります。
第4章のゾンビや、この章の Battle とよく似たイベントです。

1920体たおしたらボスを出す

1つ目は、BOSS HP の文字を最初は見えなくしておくイベントです。
条件は「At the beginning of the scene」、アクションは「Hide」で BossHPText。

2つ目（Shift + A）が、ボスを出すイベントです。
条件は2つ。

  • 「Variable value」で Kills、Sign of the test は「≥ (greater or equal to)」、値は Goal
  • 「Variable value」で BossSpawned が False

アクションは5つ。

  • 「Change variable value」で BossSpawned を set to true
  • 「Change variable value」で SpawnAngle を「= (set to)」で RandomInRange(0, 359)
  • 「Create an object」で Boss。
    X と Y は下の式、レイヤーは Base layer のまま
  • 「Show」で BossHPText
  • GoalText の「Text」を、下の文字にする
X position
Player.X() + XFromAngleAndDistance(SpawnAngle, 900)
Y position
Player.Y() + YFromAngleAndDistance(SpawnAngle, 900)
GoalText の Text
"ボスが来た！ たおせばクリア！"
BossSpawned はなんのため？ … 「Kills ≧ Goal」は、20体たおしたあとずっと「はい」のままです。
そのままだと、毎回（1秒に60回くらい）ボスが作られて、ボスだらけになってしまいます。
ボスを作ったときに BossSpawned を True にして、条件に「BossSpawned が False」を入れておくと、ボスは1回だけ作られます。
20ボスが追いかけてきて、パンチする

第4章のゾンビと同じ作り方で、3つのイベントを作ります。

  • 条件なし →「Rotate toward another object」で、Boss を Player のほうへ、Angular speed 0
  • 「Distance between two objects」で Boss と Player、距離 110、「Invert condition」を ON →「Add a force to move toward an object」で Boss を Player へ Speed 60（Instant）、「Animation (by name)」で Boss を「Walk」
  • 「Distance between two objects」で Boss と Player、距離 110（Invert は OFF）と、「Variable value」で InCar が False →「Animation (by name)」で Boss を「Punch」、「Change variable value」で PlayerHealth を「- (subtract)」で下の式
ボスのパンチでへらす量
35 * TimeDelta()

ゾンビ（12）よりずっと強いパンチです。
ボスは大きいので、近いと判断する距離も 110 にしています。

21弾とトラックでボスの体力をへらす

弾が当たったときのイベントは、ステップ4と同じ作り方です。
条件は「Collision in 3D」で、Object は Bullet、Other object は Boss。
イベントシートには「Bullet is in collision with Boss」と表示されます。
アクションは「Delete the object」で Bullet と、「Change object variable value」で Boss の Health を「- (subtract)」で 1。

トラックでひいたときのイベントも作ります。
条件は「Variable value」で InCar が True と、「Distance between two objects」で Boss と Truck、距離 160。
アクションは「Change object variable value」で Boss の Health を「- (subtract)」で下の式。

トラックでへらす量
8 * TimeDelta()

ゾンビは1回ひくとたおせましたが、ボスはトラックでひき続けている間、少しずつ体力がへっていきます。

22BOSS HP を出して、たおしたらクリアへ

BOSS HP の文字を変えるイベントを作ります。
条件は「Variable value」で BossSpawned が True。
アクションは BossHPText の「Text」で、下の式を入れます。

BossHPText に入れる式
"BOSS HP: " + ToString(max(0, ceil(Boss.Variable(Health))))

最後に、ボスをたおしたときのイベントです。
条件は「Object variable value」で、Object は Boss、Variable は Health、Sign of the test は「≤ (less or equal to)」、値は 0。
アクションは「Change the scene」で、Name of the new scene は一覧から「Clear」。

Boss.Variable(Health) と ceil() … Boss.Variable(Health) は、ボスが持っているオブジェクト変数 Health を、式の中で読み出す書き方。
トラックでひくと Health は 39.87 のように細かくへるので、ceil() で小数を切り上げて整数にします。
max(0, …) は、マイナスの数が出ないようにするためです。

5-11. ボスとたたかってみよう

23保存して Preview

保存してから Preview します。
ゾンビを20体たおすと、上の文字が「ボスが来た！ たおせばクリア！」に変わり、大きなボスが出てきます。
右上の BOSS HP が 0 になるまでたおすと、Clear のシーンに切りかわります。
今は Clear のシーンが空っぽなので、何もない画面になればOK（クリアの画面は第6章で作ります）。

20体たおすのは大変なので、ためすときはシーン変数の Goal を 2 などにすると早く確かめられます。
確かめ終わったら、Goal を 20 にもどしておこう。

💪 やってみよう

ゾンビの体力（3）、わく距離（700）、ボスの体力（40）や大きさ（210）を変えてみよう。
ボスが出るまでの数（Goal の 20）を変えて、ちょうどいいむずかしさにしてみよう。

ヒント

Goal を変えたら、GoalText の最初の文「ゾンビを20体たおすと、ボスが出てくる！」の数も同じに直そう。
わく間かくの式の 0.08 を大きくすると、早く1秒になります。
ボスを別のゾンビの見た目にしたいときは、Boss の「⋮」→「Swap assets」が使えます。

5-12. 🚨 つまずきポイント集

弾が当たってもゾンビがたおれない

原因: Health を Zombie の「オブジェクト変数」ではなく、シーン変数に作ってしまった。

直し方: 一覧の Zombie をクリックして、左の Object Variables に Health（3）があるか確かめよう。

ゾンビがわいてこない

原因: タイマーをスタートするイベント（ステップ9）がない、またはタイマーの名前がちがう。

直し方: 3か所の "SpawnTimer" が、大文字・小文字までまったく同じか確かめよう。

トラックでひいてもたおせない

原因: InCar の条件が False になっている。

直し方: ステップ6の条件をダブルクリックして、True を選びなおそう。

Kills の文字がカメラといっしょに動く・見えなくなる

原因: KillText を置いたとき、●が Base layer のままだった。

直し方: 置いた KillText をクリックして、左のレイヤーの欄を「UI」に変えよう。

20体たおしてもボスが出てこない

原因: Boss のイベントの条件がちがう、または BossSpawned が最初から True になっている。

直し方: ステップ19の条件が「The variable Kills ≥ Goal」と「The variable BossSpawned is false」になっているか確かめよう。
「Game Scene variables」で、BossSpawned の値が False になっているかも見てみよう。

ボスがたくさん出てくる

原因: ボスを出すイベントに「BossSpawned を set to true」のアクションがない。

直し方: ステップ19のアクションのいちばん上に、「Change variable value」で BossSpawned を set to true を入れよう。

「Change the scene」の一覧に Clear が出てこない

原因: Clear のシーンをまだ作っていない、または名前がちがう。

直し方: ステップ18のとおり、プロジェクトマネージャーで Clear のシーンを作ろう。
名前は大文字の C で始まる Clear です。

BOSS HP の文字が、ボスが出る前から見えている

原因: 「At the beginning of the scene」で BossHPText を Hide するイベントがない。

直し方: ステップ19の1つ目のイベントを作ろう。
