第4章

ジェムを集めてレベルアップ

📅 第4回の講習で使います（日付が決まったらここに記載）
💻 使っているPC:

🎯 この章でできるようになること

  • たおした敵の場所にジェムを落とし、近づくと吸いよせて拾える
  • 配列の変数に、文字をいくつもまとめて入れられる
  • タイムスケールで、ゲームの時間を止めたり動かしたりできる
  • 「以下の条件が一つでも真の場合」で、キーでもクリックでも選べるようにできる

4-1. この章で作るしくみ

この章で作るルール（まとめ）
条件（ゴブリン1体ずつ）体力が0以下
アクションその場所にジェムを落とす（追加）
条件ジェムが騎士の近くにある ／ ジェムが騎士にさわった
アクション騎士へ吸いよせる ／ ジェムを消して XP を1ふやす
条件XP が XPNext 以上
アクションレベルを1上げる。
時間を止めて、強化の候補を3つ出す
条件1・2・3キーか、文字のクリック
アクションえらんだ強化を Chosen に入れる
条件Chosen が決まった
アクション時間を動かして、えらんだ強化を反映する

4-2. ジェムを落とそう

1ジェムを追加する

「Game Scene」のタブで、「オブジェクト」の「＋」からアセットストアを開きます。
検索欄に gem と入れて、「Blue Gem」（作者: Kenney）を選んで追加します。
オブジェクト名は Blue_Gem になります。
ジェムもイベントで作り出すので、シーンには置かなくてOK。

2たおしたゴブリンの場所にジェムを作る

「Game Scene (イベント)」の Enemy グループで、第3章で作った「Goblin の各インスタンスごと繰り返す」のイベントにアクションを2つ足します。

  • 「オブジェクトを生成する」で Blue_Gem を X Goblin.CenterX()、Y Goblin.CenterY() に作る
  • 「スケール」で Blue_Gem を 1.2

足した2つは、ドラッグして「Goblin を削除する」より上に動かします。
先にゴブリンを消してしまうと、ゴブリンの場所がわからなくなるからです。

3シーン変数を足す

「Game Scene 変数」の画面を開き、次の変数を足して「適用」を押します。

名前型値意味
XP数値0集めたジェム（経験値）
XPNext数値8次のレベルまでに必要な XP
Level数値1今のレベル
MagnetRange数値150ジェムを吸いよせる距離
PlayerSpeed数値300騎士の速さ
Opt1・Opt2・Opt3数値1・2・3画面に出す強化の番号
OptD数値1強化の番号をえらぶための計算用
Chosen数値0えらんだ強化の番号（0 はまだえらんでいない）
UpgradeNames配列（下の6つ）強化の名前の一覧

UpgradeNames は、型を「配列」にします。
行の右の「＋」を6回押すと、0〜5 の番号の「子」ができます。
子の型をそれぞれ「テキスト」にして、次の文字を入れます。

番号テキスト
0ナイフの威力アップ
1攻撃のスピードアップ
2ナイフを1本ふやす
3足がはやくなる
4最大HPアップ＆全回復
5ナイフを投げる方向がふえる
配列（はいれつ） … 1つの変数の中に、番号つきで値をいくつも入れられる変数。
番号は 0 から始まります。
UpgradeNames[2] と書くと、2番の「ナイフを1本ふやす」が取り出せます。

4-3. ジェムを拾おう

4Gem & level グループを作る

Enemy グループの下に、新しいグループ Gem & level を作ります。
その中に、イベントを2つ作ります。

1つ目（吸いよせる）
条件は、左の一覧で Blue_Gem を選び、「2つのオブジェクト間の距離」、オブジェクト 2 は Player、距離 は MagnetRange（こんどは反転しない）。
アクションは「オブジェクトに向かって移動するフォースを追加する」で Blue_Gem を Player へ、速度 450、「瞬間的」。

2つ目（拾う）
右クリック →「追加」→「For each object」で、オブジェクト は Blue_Gem。
条件は「衝突」で Blue_Gem と Player。
アクションは「オブジェクトを削除する」で Blue_Gem、「変数の値を変更」で XP を「＋（加算）」1。

MagnetRange（マグネットの範囲） … 騎士から 150 より近いジェムは、騎士のほうへ飛んできます。
ジェムを1つずつ拾うので、ここでも「For each object」を使います。
いっぺんに2つさわっても、XP がちゃんと2ふえます。

4-4. XP バーとレベルを出そう

5XP バーとレベルの文字を置く

「Game Scene」のタブで、一覧の Health_Bar_Fill の「⋮」→「複製」を選びます。
できたオブジェクトの「⋮」→「名前を変更」で、名前を XP_Bar_Fill にします。
レイヤーの UI の丸いボタンを押してから、XP_Bar_Fill をステージに置き、X 0、Y 0、W 1280、H 10 にします。
画面のいちばん上の、うすいバーになります。

次に、「＋」→「オブジェクトの新規作成」→「テキスト」で LevelText を作ります。
最初に表示するテキスト は Lv 1。
サイズや色は KillText と同じくらいで、好きな色（写真では水色）にしてOK。
UI レイヤーの、体力バーの右（X 240、Y 16 くらい）に置きます。

6UI グループで、バーと文字を動かす

「Game Scene (イベント)」の UI グループで、条件のないイベントにアクションを2つ足します。

  • 「幅」で XP_Bar_Fill を「＝（代入）」XP / XPNext * 1280
  • LevelText の「テキスト」で「＝（代入）」"Lv " + ToString(Level)

Start グループの「シーンが始まった」には、「色合いを変更する」で XP_Bar_Fill を "80;200;255"（水色）を足します。
Health_Bar_Fill を複製したので、そのままだと赤いバーだからです。

XP / XPNext * 1280 … 体力バーと同じ考え方です。
「次のレベルまで何わり集まったか」に、画面の横はば 1280 をかけています。
ジェムを集めるほど、バーが右へのびていきます。
"Lv " + ToString(Level) は、「Lv 」という文字と、レベルの数をつなげて「Lv 2」のようにします。

4-5. レベルアップの画面を作ろう

7パネルと文字を置く

もう一度 Health_Bar_Fill を「複製」して、名前を Panel にします。
UI レイヤーに置いて、X 0、Y 0、W 1280、H 720（画面全体）にします。
エディタでは赤いしましまですが、ゲームが始まったら黒くて半分すけたパネルにします。

「テキスト」で、次の4つを作って UI レイヤーのパネルの上に置きます。

名前最初に表示するテキスト置く場所（だいたいでOK）
LevelUpTextレベルアップ！ 強化を1つえらぼう（1・2・3キー または クリック）上のほう、まん中（黄色が見やすい）
Option1Text1：X 300、Y 290
Option2Text2：X 300、Y 370
Option3Text3：X 300、Y 450

Option1Text〜3 の文字は、あとでイベントで「1：ナイフを1本ふやす」のように書きかえます。
文字がパネルにかくれてしまうときは、Panel をクリックして Z を 0 に、文字の Z を 100 にしよう（Z が大きいほど手前に出ます）。
置き終わったら、ベースレイヤーの丸いボタンを押してもどしておこう。

8ゲームが始まったら、パネルをかくす

Start グループの「シーンが始まった」に、アクションを足します。

  • 非表示 で検索 →「非表示」で Panel、LevelUpText、Option1Text、Option2Text、Option3Text（5つ）
  • 「色合いを変更する」で Panel を "0;0;0"（黒）
  • 不透明度 で検索 →「不透明度」で Panel を「＝（代入）」170（0 で透明、255 で不透明）

4-6. レベルアップのしくみを作ろう

9XP がたまったらレベルアップ

Gem & level グループに新しいイベントを作ります。
条件は2つです。

  • 「変数の値」で XP が「≧（以上）」XPNext
  • 「変数の値」で LevelingUp が「偽」

アクションは、上から順番に次のとおりです。

アクション中身
変数の値を変更XP を「−（減算）」XPNext
変数の値を変更Level を「＋（加算）」1
変数の値を変更XPNext を「＝（代入）」round(8 + Level * 6 + Level * Level * 0.5)
変数の値を変更LevelingUp を「真」に設定
タイムスケール で検索 →「シーンのタイムスケール」0
変数の値を変更Opt1 を「＝（代入）」RandomInRange(1, 6)
変数の値を変更OptD を「＝（代入）」RandomInRange(1, 5)
変数の値を変更Opt2 を「＝（代入）」下の式
変数の値を変更Opt3 を「＝（代入）」下の式
テキストOption1Text を「＝（代入）」"1：" + UpgradeNames[Opt1 - 1]
テキストOption2Text を「＝（代入）」"2：" + UpgradeNames[Opt2 - 1]
テキストOption3Text を「＝（代入）」"3：" + UpgradeNames[Opt3 - 1]
表示 で検索 →「表示」LevelUpText、Option1Text、Option2Text、Option3Text、Panel（5つ）
Opt2 の値（おまじない）
mod(Opt1 - 1 + OptD, 6) + 1
Opt3 の値（おまじない）
mod(Opt1 - 1 + mod(OptD - 1 + RandomInRange(1, 4), 5) + 1, 6) + 1
タイムスケール 0 ＝ 時間を止める … タイムスケールは、ゲームの時間の進む速さです。
1 がふつう、0 にすると時間が止まります。
ゴブリンもナイフもタイマーも止まるので、ゆっくり強化をえらべます。
LevelingUp を真にしておくのは、「今はレベルアップ中」という目じるしです。
ナイフやゴブリンを出すイベントに「LevelingUp が偽」の条件を入れておいたのは、このためです。
Opt1〜Opt3 の式（おまじない） … 1〜6 の中から、3つともちがう番号をえらぶための式です。
Opt1 はふつうにランダム。
Opt2 は、Opt1 から OptD（1〜5）だけずらした番号です。
mod(…, 6) は「6 で割ったあまり」で、6 をこえたら 1 にもどって数えるはたらきをします。
Opt3 は、OptD とはちがう量だけずらすので、Opt1 とも Opt2 ともかぶりません。
配列の番号は 0 から始まるので、UpgradeNames[Opt1 - 1] のように 1 を引いて取り出します。
XPNext の式 … round() は四捨五入です。
Level が 2 なら 8 + 12 + 2 ＝ 22、Level が 3 なら 8 + 18 + 4.5 ≒ 31 のように、レベルが上がるほど次に必要なジェムがふえていきます。
101・2・3キーか、クリックでえらぶ

新しいイベントを作ります。
1つ目の条件は「変数の値」で LevelingUp が「真」。
2つ目の条件は、検索欄に または と入れて、「または」の条件（高度 › イベントと制御フロー）を選びます。
イベントシートには「以下の条件が一つでも真の場合：」と表示されます。
その中の「副条件を追加」で、次の3つを入れます。

  • キーが押された で検索 →「キーが押された」で Num1（キーボードの上の 1）
  • 「キーが押された」で Numpad1（テンキーの 1）
  • かつ で検索 →「かつ」の条件（シートでは「以下の条件がすべて真の場合：」）。
    その中の「副条件を追加」で、左の一覧の Option1Text の「カーソル/タッチはオブジェクト上にある」と、マウスボタン で検索 →「マウスボタンを放した直後」（ボタンは Left）

アクションは「変数の値を変更」で Chosen を「＝（代入）」Opt1。

このイベントを右クリック →「コピー」→「貼り付け」で2つふやし、2番・3番用に直します。
Num1→Num2、Numpad1→Numpad2、Option1Text→Option2Text、Opt1→Opt2 のように、数字を全部かえるのを忘れずに。

「一つでも真」と「すべて真」 … 「以下の条件が一つでも真の場合」は、中の条件のどれか1つが当てはまればOK。
「以下の条件がすべて真の場合」は、中の条件が全部当てはまらないとダメ。
だから「1キー」か「テンキーの1」か「（Option1Text の上で）かつ（クリックをはなした）」のどれかで、1番がえらばれます。
「キーを押している」ではなく「キーが押された」を使うのは、1回押したら1回だけえらぶためです。
11えらんだ強化を反映する

新しいイベントを作ります。
条件は「変数の値」で LevelingUp が「真」、「変数の値」で Chosen が「>（より大きい）」0。
アクションは次のとおりです。

  • 「変数の値を変更」で LevelingUp を「偽」に設定
  • 「シーンのタイムスケール」を 1（時間を動かす）
  • 「非表示」で LevelUpText、Option1Text、Option2Text、Option3Text、Panel

次に、このイベントを右クリック →「追加」→「サブイベント」で、中にイベントを7つ作ります。

サブイベントの条件（変数の値）アクション（変数の値を変更）強化
Chosen ＝ 1KnifeDamage を「＋（加算）」1ナイフの威力アップ
Chosen ＝ 2KnifeCooldown を「＝（代入）」max(0.3, KnifeCooldown * 0.85)攻撃のスピードアップ
Chosen ＝ 3KnifeCount を「＝（代入）」min(5, KnifeCount + 1)ナイフを1本ふやす
Chosen ＝ 4PlayerSpeed を「＋（加算）」25足がはやくなる
Chosen ＝ 5MaxHealth を「＋（加算）」20、PlayerHealth を「＝（代入）」MaxHealth最大HPアップ＆全回復
Chosen ＝ 6KnifeDirs を「＝（代入）」min(8, KnifeDirs * 2)ナイフを投げる方向がふえる
（条件なし）Chosen を「＝（代入）」0えらんだ番号をもどす
max と min で「ここまで」を決める … max(0.3, …) は「0.3 より小さくならない」、min(5, …) は「5 より大きくならない」という意味です。
攻撃のスピードは 0.85 倍ずつ速くなりますが、0.3 秒より速くはなりません。
ナイフは5本まで、方向は 1→2→4→8 と倍になって、8方向までです。
最後に Chosen を 0 にもどすのは、次のレベルアップまでこのイベントが動かないようにするためです。
12騎士の速さを PlayerSpeed にする

Player グループに、条件のないイベントを作ります。
アクションは、左の一覧で Player を選び、「最高速度」（トップダウンの設定）で「＝（代入）」PlayerSpeed。
イベントシートには「Player の最大速度を変更する：PlayerSpeed を代入」と表示されます。
これで「足がはやくなる」をえらぶと、騎士が速くなります。

13保存して プレビュー

ゴブリンをたおすと、青いジェムが落ちます。
近づくとジェムが吸いよせられ、拾うと画面の上の水色のバーがのびます。
バーがいっぱいになると時間が止まり、強化の候補が3つ出てきます。
1・2・3キーかクリックでえらぶと、ゲームが動き出して、えらんだ強化が効けば成功！

💪 やってみよう

MagnetRange を大きくしたり、XPNext の式の数を変えたりして、レベルアップのペースを調整してみよう。
よゆうがある人は、7つ目の強化を考えてみよう。

ヒント

7つ目をふやすときは、UpgradeNames に6番の子を足し、Opt の式の 6 を 7 に、5 を 6 に、4 を 5 に変えます。
そして、反映のイベントに「Chosen ＝ 7」のサブイベントを足そう。
たとえば「MagnetRange を 50 ふやす」（ジェムを遠くから吸いよせる）などがおすすめです。

4-7. 🚨 つまずきポイント集

ジェムが出ない・左上に出る

原因: ジェムを作るアクションが、「Goblin を削除する」より下にある。

直し方: Blue_Gem の2行を、「Goblin を削除する」より上にドラッグしよう。

レベルアップの画面がずっと出たまま・ゲームが止まったまま

原因1: えらぶイベントの条件が「キーを押している」になっている、またはキーの名前がちがう。
→ 「キーが押された」で Num1 などになっているか確かめよう。

原因2: 反映のイベントで、タイムスケールを 1 にもどしていない。
→ 「シーンのタイムスケール」を 1 にするアクションがあるか確かめよう。

強化の文字が「1：」のまま、または同じ強化が2つ出る

原因: UpgradeNames の子の型が「テキスト」になっていない、または Opt の式の写しまちがい。

直し方: 子の型と文字を確かめて、Opt2・Opt3 の式はコピーボタンで写しなおそう。

パネルが赤いまま・まっ黒で何も見えない

原因: Start の「色合い」や「不透明度」が Panel になっていない、または不透明度が 255。

直し方: Panel の色合い "0;0;0"、不透明度 170 になっているか確かめよう。
