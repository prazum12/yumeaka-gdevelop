第3章

ゴブリンがおしよせる

📅 第3回の講習で使います（日付が決まったらここに記載）
💻 使っているPC:

🎯 この章でできるようになること

  • オブジェクト変数で、敵1体ずつに体力を持たせられる
  • 画面の外から、敵を次々に出てこさせられる
  • 「For each object」のイベントで、1体ずつ順番に調べられる
  • UI レイヤーに体力バーとたおした数を出し、体力が0でやりなおしにできる

3-1. この章で作るしくみ

この章で作るルール（まとめ）
条件（いつも）
アクションゴブリンが騎士のほうへ動く。
かべからは押しもどす
条件ナイフがゴブリンに当たった
アクションナイフを消して、ゴブリンの体力をへらす
条件（ゴブリン1体ずつ）体力が0以下
アクションゴブリンを消して、たおした数を1ふやす
条件タイマーが 0.9 秒をこえた（ゴブリンが250体より少ない）
アクション画面の外のランダムな方向にゴブリンを作る
条件ゴブリンが騎士にさわっている
アクション騎士の体力をへらす
条件（いつも）／ 体力が0以下
アクション体力バーとたおした数を出す ／ 最初からやりなおす

3-2. ゴブリンと変数を用意しよう

1ゴブリンを追加する

「オブジェクト」の「＋」からアセットストアを開き、goblin で検索して「Goblin」（Dungeon パックのもの）をプロジェクトに追加します。
アニメーションは「Idle」と「Run」の2つです。
ゴブリンはイベントで作り出すので、シーンには置かなくてOK。
もし置いてしまったら、シーンのゴブリンをクリックして Delete キーで消しておこう。

2ゴブリンに体力（オブジェクト変数）を持たせる

右の一覧の Goblin をクリックすると、左に Goblin のプロパティが出ます。
「オブジェクト変数」の右の「＋」を押して、変数を作ります。
名前を Health、型は「数値」、値を 1 にします。
ナイフ1回でたおれるゴブリンになります。

オブジェクト変数 … オブジェクト1つ1つが、べつべつに持っている変数。
ゴブリンが10体いたら、10体それぞれが自分の Health を持っています。
だから、ナイフが当たったゴブリンだけ体力がへります。
3シーン変数を足す

第2章と同じように「Game Scene 変数」の画面を開き、次の7つを足して「適用」を押します。

名前型値意味
PlayerHealth数値100騎士の体力
MaxHealth数値100体力の最大
Kills数値0たおした数
KnifeDamage数値1ナイフ1本のダメージ
SpawnAngle数値0ゴブリンを出す方向
Elapsed数値0たった時間（第5章で使う）
SpawnFactor数値1出てくる間隔の倍率（第5章で使う）

3-3. ゴブリンが追いかけてくる

「Game Scene (イベント)」で新しいグループ Enemy を作ります。
グループは Player・Knife のグループの下に置こう。

4騎士のほうへ動かす

条件のないイベントを作ります。
アクションは4つです。

  • オブジェクトに向かって移動 で検索 →「オブジェクトに向かって移動するフォースを追加する」、オブジェクト は Goblin、目標オブジェクト は Player、速度 は 100、下は「瞬間的」のまま
  • 「アニメーション名」で Goblin を「Run」
  • 分離 で検索 →「オブジェクトを分離する」、オブジェクト は Goblin、オブジェクト（これは移動しません） は Wall_Obstacle
  • もう1つ「オブジェクトを分離する」で、Goblin と Plant_Obstacle

イベントシートには「Goblin を 100 ピクセル/秒の速度で一回移動する」「Goblin を Wall_Obstacle から遠ざける」のように表示されます。
第5章で、この 100 を「時間がたつほど速くなる式」に変えます。

条件のないイベント … 条件を入れないと、「いつも」（1秒に60回くらい）アクションが動きます。
瞬間的 の力を毎回かけるので、ゴブリンはずっと騎士を追いかけ続けます。
「オブジェクトを分離する」は、重なったら1つ目を押しもどすアクション。
これで、ゴブリンもかべをすりぬけなくなります。
5ゴブリンの向きを変える

新しいイベントの条件に、X 座標 で検索 →「X 座標」を入れます。
オブジェクト は Goblin、テスト記号 は「>（より大きい）」、値は Player.X()。
アクションは「オブジェクトを水平方向に反転させる」で Goblin を「はい」。

もう1つイベントを作り、テスト記号 を「≦（以下）」、反転 を「いいえ」にします。
騎士より右にいるゴブリンは左を、左にいるゴブリンは右を向きます。

3-4. ナイフでたおそう

6ナイフが当たったら体力をへらす

新しいイベントの条件に、衝突 で検索 →「衝突」を入れます。
1つ目の オブジェクト は Knife、2つ目は Goblin。
アクションは3つです。

  • 「オブジェクトを削除する」で Knife
  • オブジェクト変数の値を変更 で検索 →「オブジェクト変数の値を変更」、オブジェクト は Goblin、変数 は Health、演算子 は「−（減算）」、値 は KnifeDamage
  • 色合い で検索 →「色合いを変更する」、Goblin を "255;80;80"（赤っぽくする）
"255;80;80" … 色を「赤;緑;青」の3つの数（0〜255）で表したもの。
"255;255;255" は白（もとの色のまま）です。
赤だけ大きくすると、赤っぽい色になります。
第5章で体力が多いゴブリンが出てくると、「1回当たったゴブリン」が見分けられて便利です。
71体ずつ調べて、体力が0ならたおす

Enemy グループの中のイベントを右クリックして、「追加」→「For each object」を選び（メニューは英語のまま表示されます）、オブジェクト は Goblin にします。
イベントシートには「Goblin の各インスタンスごと繰り返す (デフォルトの順序)：」と表示されます。

このイベントの条件に、オブジェクト変数の値 で検索 →「オブジェクト変数の値」、オブジェクト は Goblin、変数 は Health、テスト記号 は「≦（以下）」、値は 0。
アクションは2つです。

  • 「オブジェクトを削除する」で Goblin
  • 「変数の値を変更」で Kills を「＋（加算）」1
For each object（オブジェクトごとに繰り返し） … ゴブリンを1体ずつ順番に取り出して、条件とアクションを調べるイベント。
ふつうのイベントだと、同じ瞬間に2体たおれても「まとめて1回」と数えてしまい、Kills が1しかふえません。
1体ずつ調べれば、2体なら2回、ちゃんと数えられます。
第4章では、たおれたゴブリン1体ずつの場所にジェムを落とすのにも使います。

3-5. ゴブリンをどんどん出そう

80.9秒ごとに、画面の外からゴブリンを出す

Enemy グループに新しいイベントを作ります。
条件は3つです。

  • 「変数の値」で LevelingUp が「偽」
  • 「シーンタイマーの値」で "EnemyTimer" が「≧（以上）」0.9
  • 左の一覧で Goblin を選び、「シーン上のオブジェクトインスタンスの数」、テスト記号 は「<（より小さい）」、比較する値 は 250

アクションは5つです。

  • 「シーンタイマーをスタート（またはリセット）する」で "EnemyTimer"
  • 「変数の値を変更」で SpawnAngle を「＝（代入）」RandomInRange(0, 359)
  • 「オブジェクトを生成する」で Goblin を、下の X・Y の式の場所に作る
  • 「スケール」で Goblin を 3
  • 「オブジェクト変数の値を変更」で Goblin の Health を「＝（代入）」1
X 座標
Player.CenterX() + XFromAngleAndDistance(SpawnAngle, 760)
Y 座標
Player.CenterY() + YFromAngleAndDistance(SpawnAngle, 760)
XFromAngleAndDistance(角度, 距離) … 「この角度に、この距離だけ進んだら、X はどれだけ動くか」を教えてくれる式。
Y のほうは YFromAngleAndDistance です。
騎士のまん中から、ランダムな角度（0〜359度）に 760 はなれた場所にゴブリンを作ります。
画面の横はばは 1280 なので、760 はなれていれば、だいたい画面の外から歩いてきます。
250体より多くならないようにしているのは、ゲームが重くなりすぎないためです。
9シーンが始まったら "EnemyTimer" もスタート

Start グループの「シーンが始まった」のイベントに、アクションを1つ足します。
「シーンタイマーをスタート（またはリセット）する」で "EnemyTimer"。
これがないと、ゴブリンが1体も出てきません。

10ゴブリンにさわると体力がへる

Enemy グループのいちばん下に新しいイベントを作ります。
条件は「衝突」で Goblin と Player。
アクションは「変数の値を変更」で PlayerHealth を「−（減算）」、値 は下の式。

値
20 * TimeDelta()
TimeDelta() … 前の画面から今の画面まで、何秒たったかを教えてくれる式（だいたい 0.016 秒）。
20 × TimeDelta() を毎回引くと、ちょうど「1秒で20へる」になります。
PCの速さがちがっても、へる速さは同じになります。

3-6. 体力バーとたおした数を出そう

11UIレイヤーを作る

「Game Scene」のタブにもどります。
右下の「レイヤー」で「＋」を押して新しいレイヤーを作り、名前を UI にして Enter。
UI の右の丸いボタンを押して、これから置くものが UI レイヤーに入るようにします。

レイヤー … 透明なシートを重ねるように、絵を重ねるしくみ。
体力バーや数字は UI レイヤーにまとめておくと、ゴブリンやナイフの上に、いつも見えるように表示されます。
12体力バー・ドクロ・数字を追加する

「＋」からアセットストアを開き、health bar で検索します。
「Health Bar Fill」（作者: Pixel-boy、CC0）を選んで追加します。
これは「タイルスプライト」（タイル状にくり返す画像）なので、横の長さを自由に変えられます。

次に skull で検索して、「Skull」（作者: Alex's Assets、CC0）を追加します。
たおした数のマークに使います。

最後に、たおした数の文字を作ります。
「＋」→「オブジェクトの新規作成」→ テキスト で検索 →「テキスト」を選びます。
オブジェクト名 を KillText、サイズ を 36、「太字」にチェック。
最初に表示するテキスト は 0。
「輪郭」の 有効 にチェックして、太さ を 4 にして「適用」。

13画面の左上にならべる

3つをステージにドラッグして置き、左の数字で位置と大きさを決めます。
置いたものをクリックすると、左に X・Y・W（幅）・H（高さ）が出ます。
いちばん下のレイヤーが「UI」になっているかも確かめよう。

  • Health_Bar_Fill … X 20、Y 20、W 200、H 24（W と H の右の鎖のマークを押して、たて横の比率を自由にしてから入れる）
  • Skull … X 20、Y 56、W 40
  • KillText … X 70、Y 52

置き終わったら、レイヤー の「ベースレイヤー」の丸いボタンを押して、もとにもどしておこう。

14体力バーと数字を動かす

「Game Scene (イベント)」にもどり、いちばん下に新しいグループ UI を作ります。
その中に条件のないイベントを作り、アクションを2つ入れます。

  • 幅 で検索 →「幅」、Health_Bar_Fill を「＝（代入）」、値 は下の式
  • 左の一覧で KillText を選び、「テキスト」で「＝（代入）」ToString(Kills)
Health_Bar_Fill の幅
max(0, PlayerHealth) / MaxHealth * 200
バーの幅の式 … PlayerHealth ÷ MaxHealth で「体力が何わり残っているか」を出して、200（バーの長さ）をかけています。
体力が 100 のうち 50 なら、0.5 × 200 ＝ 100 の長さです。
max(0, PlayerHealth) は、体力がマイナスになってもバーの幅がマイナスにならないようにするためのものです。
ToString() は数を文字に変える式で、Kills を文字にして KillText に出します。
15体力が0になったらやりなおし

UI グループに新しいイベントを作ります。
条件は「変数の値」で PlayerHealth、テスト記号 は「≦（以下）」、値は 0。
アクションは シーンを変更 で検索 →「シーンを変更する」、一覧から「Game Scene」。
同じシーンに変えると、最初からやりなおしになります（第6章でゲームオーバーの画面に変えます）。

3-7. 動かしてみよう

16Enemy グループを見直して プレビュー

Enemy グループは、上から「追いかける」「向き2つ」「ナイフが当たった」「1体ずつたおす」「ゴブリンを出す」「さわるとダメージ」の順にならんでいます。

保存してから プレビュー します。
画面の外から、ゴブリンが次々に歩いてきます。
ナイフが当たるとゴブリンが消えて、ドクロの横の数字がふえます。
ゴブリンにさわられると、左上の赤いバーがへっていきます。
バーがなくなると、ゲームが最初から始まります。

💪 やってみよう

ゴブリンの速さ（100）、出てくる間隔（0.9秒）、ダメージ（20）を変えて、むずかしさを調整してみよう。
試したら、もとの数にもどしておこう。

ヒント

速さは「オブジェクトに向かって移動するフォースを追加する」、間隔は "EnemyTimer" の条件、ダメージは 20 * TimeDelta() の 20 です。
第5章では、これらを「時間がたつほどむずかしくなる式」に変えます。

3-8. 🚨 つまずきポイント集

ゴブリンが1体も出てこない

原因: 「シーンが始まった」で "EnemyTimer" をスタートしていない、またはタイマーの名前がちがう。

直し方: 2か所とも "EnemyTimer" になっているか、大文字・小文字まで確かめよう。

ゴブリンがとても小さい

原因: 作ったあとの「スケール」を入れていない。

直し方: オブジェクトを生成する のすぐ下に「スケール」で 3 を入れよう。

ナイフが当たってもたおれない

原因: Health をシーン変数に作ってしまった、または「オブジェクト変数の値」ではなく「変数の値」を使った。

直し方: 一覧の Goblin をクリックして、左の オブジェクト変数 に Health（1）があるか確かめよう。

体力バーや数字がゴブリンにかくれる・いっしょに動いてしまう

原因: UI レイヤーではなく ベースレイヤー に置いた。

直し方: 置いたものをクリックして、左の レイヤー が「UI」になっているか確かめよう。

すぐにやりなおしになる

原因: 値 を 20 だけにして、TimeDelta() をかけていない。

直し方: 20 * TimeDelta() になっているか確かめよう。
